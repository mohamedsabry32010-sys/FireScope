FireScope — NASA Space Apps Challenge prototype

التشغيل:
1) ثبّت Python 3.10 أو أحدث.
2) فك ضغط الملف.
3) افتح Terminal داخل المجلد ونفّذ:
   pip install -r requirements.txt
   streamlit run app.py

مصدر البيانات:
- Demo data: بيانات اصطناعية لتجربة الواجهة فقط.
- Upload FIRMS CSV: ارفع ملف CSV من NASA FIRMS.
- NASA FIRMS API: أدخل MAP_KEY مجاني من https://firms.modaps.eosdis.nasa.gov/api/
  لا تشارك المفتاح مع أي شخص.

المزايا:
خريطة تفاعلية، مرشحات للأقمار الصناعية والثقة، مقارنة تقريبية MODIS/VIIRS،
تقويم نشاط يومي، كشف إحصائي للنشاط غير المعتاد، FRP، رسوم بيانية،
تقرير قابل للتنزيل وتصدير CSV.

مهم علمياً:
المطابقة بين المستشعرات تقريبية (نفس التاريخ وفي نطاق ~1 كم) وليست تحققاً رسمياً.
الداتا التجريبية اصطناعية وليست بيانات ناسا.
النقاط الساخنة ليست حدود حرائق مؤكدة. لا يتنبأ التطبيق بحرائق مستقبلية ولا يستبدل جهات الطوارئ.
قبل العرض: اختبر API بمفتاح فعلي، واختَر منطقة جغرافية محددة، وقارن النتائج مع NASA FIRMS Map Viewer.
